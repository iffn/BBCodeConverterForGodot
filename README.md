# BBCodeConverterForDotNetGodot

This was created with and for `Godot_v4.4.1-stable_mono_win64`

How to use:
- Download the DotNet version of Godot 4.4.1 [[Link]](https://godotengine.org/download/archive/4.4.1-stable/)
- Create a new project
- Add this repository as a sub folder
- Build the scripts (adding a new C# script to the folder lets the compile button appear)
- Open and run `BBCodeConverter.tscn`
